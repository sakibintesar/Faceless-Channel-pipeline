# Compliance Checklist — Before Every Upload

## YouTube
- [ ] Original commentary or analysis (not reused content — YPP policy)
- [ ] Varied structure across videos (inauthentic-content policy)
- [ ] AI disclosure: "This video was created with AI-assisted scripting and a synthetic voice."
- [ ] Affiliate disclosure in description (FTC + YouTube terms)
- [ ] Only Pexels/Pixabay assets or original renders (no copyright strikes)
- [ ] Max 3 uploads/day (`config/upload_schedule.yaml`)

## Instagram / Facebook
- [ ] Professional account (Creator) — required for Bonuses
- [ ] AI disclosure in caption
- [ ] Affiliate disclosure ("paid partnership" label where applicable)
- [ ] Max 2 IG + 1 FB uploads/day
- [ ] Bonuses express-interest form submitted (invite-based)

## Bilibili (if used)
- [ ] Mandarin TTS voice (zh-CN-*)
- [ ] Identity verification completed
- [ ] Danmaku engagement in the first hour after upload

## FTC / Affiliate
- [ ] "Disclosure: some links are affiliate links — I may earn a commission at no extra cost to you."
- [ ] No medical/financial guarantees — hedged claims only ("can earn", "typically")
- [ ] Product claims fact-checked (stage 4: attested only, or flagged for rewrite)

## SIMURG
- [ ] Every script passed guard (state=clean)
- [ ] Every caption/SEO string passed guard
- [ ] Fact-check report saved to `analytics/factcheck_*.json`

## Zero-dollar audit (monthly)
- [ ] Total spend = $0 (or LLM tokens only)
- [ ] All tools on free tiers
- [ ] No paid subscriptions crept in
